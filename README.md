# MiniExchange

**Назначение программы**

MiniExchange — учебный локальный симулятор криптовалютной биржи. Конечная цель —
собственный биржевой движок на C++17 и торговый веб-интерфейс для пары BTC/USD,
с виртуальными счетами участников и торговыми ботами. Используются виртуальные
активы; реальные биржевые API и настоящие денежные операции не требуются.

Сейчас реализован только базовый Matching Engine с лимитными заявками,
консольным примером и инфраструктурой первого домашнего задания: тестами,
бенчмарками, CI/CD и документацией API.

[GitHub Actions](https://github.com/TEMPORARY1953/MiniExchange/actions)
· [Документация API на GitHub Pages](https://temporary1953.github.io/MiniExchange/)

---

**Основные возможности — реализовано**

- **Лимитные заявки BUY/SELL:** сопоставление по лучшей цене и FIFO внутри уровня.
- **Полное и частичное исполнение:** сделка проходит по цене заявки, уже стоящей
  в стакане; неисполненный остаток сохраняется.
- **Биржевой стакан:** хранение активных заявок и получение снимка каждой стороны
  в порядке цены и FIFO.
- **Проверка данных:** положительные ID, цена и количество, допустимая сторона,
  уникальность ID за всё время жизни стакана.

Цена задаётся в целых тиках, количество — в целых единицах. Ядро однопоточное,
обслуживает один инструмент и не выполняет ввод/вывод.
Алгоритм и пример исполнения приведены в [Pipeline.md](Pipeline.md).

**Функциональные требования к конечному проекту**

Следующие требования описывают завершённую систему. Рыночные заявки, отмена,
веб-терминал, счета и боты пока не реализованы.

1. **Биржевой движок (C++):**
   Принимать лимитные и рыночные заявки BUY/SELL. Лимитная заявка задаёт предельную
   цену, рыночная исполняется по доступным встречным ценам. Сопоставлять заявки
   по приоритету цены, затем времени поступления (FIFO), поддерживать полное
   и частичное исполнение. Хранить и обновлять стакан, позволять отменять
   активные заявки, включая неисполненный остаток.

2. **Торговый терминал:**
   Предоставлять локальный веб-интерфейс, открываемый в браузере. Отображать
   биржевой стакан, позволять создавать и отменять заявки. Показывать историю
   совершённых сделок и график изменения цены, построенный на основе этих сделок.

3. **Симуляция биржи:**
   Поддерживать одну торговую пару BTC/USD, виртуальные счета и балансы участников.
   При выставлении заявки проверять доступные средства и резервировать их;
   после сделок обновлять балансы, при отмене освобождать резерв неисполненной
   части. Моделировать активность участников рынка.

4. **Алгоритмическая торговля:**
   Запускать торговых ботов с различными простыми стратегиями. Боты должны
   взаимодействовать с общим биржевым движком через те же проверки заявок
   и средств, что и пользователь. Собирать статистику торгов и предоставлять
   возможность сравнивать результаты стратегий.

**Системные требования**

- **Для текущей версии:** компилятор с поддержкой C++17 и CMake 3.24+.
  Сборка и тесты проверены в CI на Ubuntu и Windows; для Windows подходит
  Visual Studio 2022.
- **Зависимости:** GoogleTest 1.17.0 и Google Benchmark 1.9.4 загружаются CMake
  с GitHub при первой полной конфигурации. Для генерации документации нужен
  Doxygen 1.9.1+.
- **Для конечной версии:** браузер для локального торгового терминала.
  Технология backend и веб-интерфейса пока не выбрана.

**Архитектура программы**

В текущей версии `include/mini_exchange/` содержит публичные структуры и API,
`src/` — независимое ядро, `app/` — консольный пример. Тесты находятся в `tests/`,
бенчмарки — в `benchmarks/`, документация API — в `docs/` и `Doxyfile`.
Файл `.github/workflows/ci.yml` задаёт сборку, проверки и публикацию документации.

В конечной системе предполагается следующее разделение:

- **C++ Matching Engine:** хранит стакан, сопоставляет и отменяет заявки,
  возвращает результаты исполнения. Остаётся независимым от сети и интерфейса.
- **Backend:** принимает запросы терминала и ботов, проверяет и резервирует
  средства, передаёт заявки движку. По результатам сделок обновляет балансы,
  историю и данные для отображения.
- **Браузерный интерфейс:** передаёт backend команды создания и отмены заявок,
  получает стакан, историю сделок и данные графика цены.
- **Торговые боты:** получают рыночные данные через backend и отправляют заявки
  в общий движок; результаты используются для статистики и сравнения стратегий.

Поток данных: терминал или бот → backend → Matching Engine → backend →
обновлённые балансы, стакан, история сделок и график.

**Сборка и запуск**

Команды из корня проекта собирают текущую версию и запускают консольный пример:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel 2
cmake --build build --config Release --target run_demo
```

Для Visual Studio 2022 в первой команде можно указать
`-G "Visual Studio 17 2022" -A x64`. Пример выводит сделки и состояние стакана;
запуска веб-терминала в текущей версии нет.

Проверка корректности и производительности:

```sh
ctest --test-dir build -C Release --output-on-failure --no-tests=error
cmake --build build --config Release --target run_benchmarks
```

Бенчмарки выводятся в консоль и сохраняются в `build/benchmark.json`.
Методика, результаты и выводы: [test&research.md](test&research.md).

Генерация документации API:

```sh
cmake -S . -B build-docs -DBUILD_TESTING=OFF -DMINI_EXCHANGE_BUILD_BENCHMARKS=OFF -DMINI_EXCHANGE_BUILD_DOCS=ON
cmake --build build-docs --target docs
```

Результат — `build-docs/docs/html/index.html`. GitHub Actions при каждом push
выполняет сборку, тесты, бенчмарки и генерацию Doxygen; из основной ветки
документация публикуется на GitHub Pages.

---

**Расширяемость**

Независимое C++-ядро позволяет подключить backend и браузерный терминал отдельными
адаптерами. Простые стратегии ботов можно добавлять через общий интерфейс
взаимодействия с биржей, сохраняя единые правила исполнения и проверки средств.
