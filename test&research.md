# Тесты и бенчмарки MiniExchange

## Методика

Unit-тесты используют GoogleTest 1.17.0 и проверяют публичный API:
ценовой приоритет и FIFO, полное и частичное исполнение, переход между уровнями,
остатки и снимки стакана, некорректные данные и повторные ID.
Сценарии сопоставления проверяются для обеих сторон заявки.

Google Benchmark 1.9.4 измеряет обработку пакетов в Release:

| Сценарий | Работа за одну итерацию | Входящих заявок |
| --- | --- | ---: |
| `BM_InsertNonCrossing/N` | N покупок на 32 уровнях без сделок | N |
| `BM_MatchPairs/N` | N пар: продажа 10 единиц по 100, покупка по 101 | 2N |
| `BM_SweepPriceLevels/N` | N продаж на 32 уровнях и покупка с остатком в 1 единицу | N + 1 |

Для каждого сценария `N = 128` и `4096`: три повторения, минимум 0,1 с на замер.
Время включает создание и уничтожение стакана, выделение памяти, проверку ID
и сопоставление. Ввод/вывод и снимки стакана не измеряются.
`CPU` — процессорное время всего пакета, `items_per_second` — входящие заявки в секунду.

Команды запуска приведены в [README.md](README.md#тесты-и-бенчмарки).

## Результаты

В [успешном запуске CI/CD](https://github.com/TEMPORARY1953/MiniExchange/actions/runs/40546110727)
все **22 теста прошли на Ubuntu и Windows**, бенчмарки выполнены в CI.
Численные результаты доступны в журналах; `tests.xml` и `benchmark.json` сохраняются
как артефакты. [Doxygen-документация опубликована на GitHub Pages](https://temporary1953.github.io/MiniExchange/).

Ниже сохранены локальные измерения от **27 октября 2026, 19:09:30 +03:00**:
Windows x64, MSVC 19.44.35228.0, CMake 3.31.6, Release.
Google Benchmark сообщает 24 логических процессора и частоту 2496 МГц.
Значения — средние трёх повторений из `build/benchmark.json` этого запуска.

| Сценарий | N | CPU на пакет, мкс | Входящих заявок/с |
| --- | ---: | ---: | ---: |
| Добавление без пересечения | 128 | 14,532 | 8 835 224 |
| Добавление без пересечения | 4096 | 488,281 | 8 505 116 |
| Встречные пары | 128 | 33,715 | 7 611 885 |
| Встречные пары | 4096 | 1067,547 | 7 673 670 |
| Проход по ценовым уровням | 128 | 16,276 | 7 945 330 |
| Проход по ценовым уровням | 4096 | 435,479 | 9 437 060 |

Время пакета не является задержкой одной заявки. Короткие замеры зависят от
таймера и нагрузки машины: коэффициент вариации CPU для вставки при N = 4096
составил 14,29%. Для сравнения производительности нужны одинаковые условия
и более длительные запуски; пороги производительности в CI не заданы.
